# zacsadan.github.io

Academic website of Dr. Zac Sadan, published with GitHub Pages at
<https://zacsadan.github.io>.

The site is generated by a small Python script, and **content is kept separate from
design**:

```
config.yml                  site settings: URL, languages, navigation menu
content/
  en/data/*.yml             structured data (edit these most often)
    site.yml                  name, positions, bio, links
    publications.yml          working papers, articles, talks, patents
    research.yml              research themes (shown on the home page)
    cv.yml                    education, appointments, experience, honors
    software.yml              GitHub projects
    ui.yml                    interface labels (menu, headings) for translation
  en/pages/**.md            pages: front matter + Markdown text
    teaching/<course>/        one folder per course; one .md file per class/year
  assets/img/               images (profile photo, teaching galleries)
theme/                      the design (swap this folder to restyle the site)
  templates/*.html          Jinja2 layouts; a page's `layout:` picks one
  static/css/style.css      colors, fonts and layout (tokens at the top)
  static/js/site.js         mobile menu and image lightbox
build.py                    builds everything into _site/
```

## Common edits

| Task | Where |
|------|-------|
| Add a publication / move a working paper to "published" | `content/en/data/publications.yml` |
| Change positions or bio | `content/en/data/site.yml` |
| Add a profile photo | save as `content/assets/img/profile.jpg`, then set `photo: img/profile.jpg` in `site.yml` |
| Add a new class year | copy e.g. `content/en/pages/teaching/emba-entrepreneurship-workshop/2026.md` to `2027.md`; put images in `content/assets/img/teaching/<course>/` |
| Change colors / fonts | variables at the top of `theme/static/css/style.css` |
| Replace the whole design | replace `theme/` (or point `theme:` in `config.yml` to another folder) |

## Preview locally

```bash
pip install -r requirements.txt
python build.py --serve        # http://localhost:8000
```

## Publish

Every push to `main` runs `.github/workflows/deploy.yml`, which builds the site and
deploys it to GitHub Pages. One-time setup: in the repository **Settings → Pages**,
set **Source** to **GitHub Actions**.

## Adding Hebrew (future)

The build already supports multiple languages and right-to-left layout:

1. Copy `content/en/` to `content/he/` and translate the YAML and Markdown files
   (including `ui.yml`).
2. Uncomment the `he` entry under `languages:` in `config.yml`.

The Hebrew site is built under `/he/`, with `dir="rtl"`, and a language switch
appears in the menu. The stylesheet uses logical CSS properties, so the layout
mirrors automatically, and the Assistant font includes Hebrew glyphs.
